把 STEM 实验与可视化带入你的网页

Open Lab Components 是面向教学网站、学习应用和开发者的开源 STEM 教育组件库。组件覆盖物理、化学、生物、数学与科学主题，可直接预览；开发者可按项目需要嵌入 HTML 组件，或使用 JavaScript API 与 MCP 服务集成。

常见问题

这些 STEM 教育组件适合哪些场景？

可用于课堂演示、在线课程、教学网站和学习应用，也适合把抽象的科学概念转成可观察、可操作的可视化内容。使用前可先在组件目录中预览效果，再选择适合课程或页面的示例。

如何把组件嵌入自己的网站？

先在组件目录中找到目标示例并查看对应使用说明，再按项目需要通过 HTML 片段或 JavaScript API 集成；MCP server 也支持 AI 应用发现和调用组件。完成后建议在自己的页面中检查尺寸、交互和移动端显示效果。

组件覆盖哪些学科？

目前目录包含物理、化学、生物、数学、科学和计算机相关组件，既有实验器材与结构示意，也有可调整参数的交互演示。你可以按学科、分类或名称搜索，快速找到合适的示例。

可以先在线预览，再决定是否使用吗？

可以。打开组件目录后可查看组件预览；需要进一步测试时，进入预览页面调整支持的参数并查看示例代码。预览结果能帮助你判断组件是否适合当前场景，但集成效果仍建议在自己的页面中验证。

组件可以免费用于商业项目吗？

项目按 MIT 许可证开源，许可范围允许商业使用、修改和再分发。使用或分发时请保留许可证要求的版权与许可声明；如果你的项目还包含第三方资源，也要另外确认那些资源的许可条件。

如何反馈问题或参与贡献？

遇到组件显示异常、使用疑问或有改进建议时，可以在 GitHub 仓库提交 Issue；如果准备了代码或新组件，也可以按贡献指南提交 Pull Request。提交前请附上组件名称、复现步骤和预期效果，方便定位问题。
